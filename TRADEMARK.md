# Trademark policy

The Apache License, Version 2.0 covers the **code** in this repository. It does
not grant any right to the name `ivar`, the ivar wordmark, or the ivar symbol —
Apache-2.0 says so itself, in section 6. This file says what you may do with
them anyway, so that you do not have to ask for the ordinary cases.

The marks are held by Gabriel Menezes, the same holder as the copyright in
[NOTICE](NOTICE).

## You do not need to ask

- **Say that you use ivar.** "Built with ivar", "works with ivar", "an ivar
  hall" — describing a true relationship to this project is nominative use and
  it is always fine.
- **Write about ivar.** Articles, talks, tutorials, courses, comparisons and
  criticism, using the name and the marks to refer to the project.
- **Fork the code.** Apache-2.0 already grants this and nothing here narrows it.
  A fork may state that it is a fork of ivar.
- **Distribute unmodified builds** — a package, a bottle, an AUR entry — under
  the name `ivar`, as long as what you ship is what this repository produces.
- **Use the marks in the shapes they come in.** Resize them; use the
  monochrome version. Do not redraw them.

## Ask first

- **Naming a modified build `ivar`.** If you change behaviour, ship it under
  your own name. "Based on ivar" is accurate and available; calling it `ivar` is
  not, because someone will file the resulting bug here.
- **Names built on the mark** — `ivar-cloud`, `ivarhub`, `ivar.io` — for a
  product, a service or an organisation. A plugin or an integration named
  `something-for-ivar` is fine and needs no permission.
- **Anything that reads as official.** Logos on a landing page, a conference
  booth, merchandise, a course sold as "the official ivar training".
- **Domains and social handles** that a reasonable person would take for this
  project.

Open an issue. That is the whole process.

## Not allowed

Presenting a modified version as if it were this project; suggesting
endorsement, affiliation or origin that does not exist; registering the marks or
anything confusingly similar; using the marks in a way that implies ivar talks
to a server, holds an account, or has a hosted offering — because it does not,
and that is the one claim this project cannot let anyone make on its behalf.

## Assets and specification

The wordmark and symbol source files, the accent colour and the usage rules
(clear space, minimum size, prohibited alterations) live with the brand
specification. If you need the marks for a use listed above, take them from
there rather than tracing them from a screenshot.
