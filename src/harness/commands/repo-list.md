# Repo List

`/ivar-repo-list` lists all repositories registered in the hall manifest, along
with features, sessions, and promoted repos.

## Usage

```bash
ivar repo list
```

For the hall-wide view including features and sessions:

```bash
ivar status
```

## Output

`ivar repo list` shows all repos with their name, default branch, and URL.
`ivar status` additionally shows features, sessions, lifecycle state, and
promoted repos per feature.
